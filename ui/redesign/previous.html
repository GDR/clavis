Clavis / macOS 26–27 interaction studies

Five ways to work.
One clear access model.

Explore five native macOS directions for managing keys and application access. Each is interactive, with the same domain model and a different starting point.

01 / Key-first · Finder / Passwords

Library

A familiar three-column workspace. Browse keys, select a key, and inspect its policy and access without losing your place.

Explore prototype ↗
02 / Table-first · compact key browser

Key Table

Browse a compact table of keys, purpose, protection and status. Open settings for the selected key, with app icons and explicit access.

Explore prototype ↗
03 / Key-first · settings window

Key Settings

Select a key in the sidebar to configure authentication and application access. Each key has its own settings, with no global authentication screen.

Explore prototype ↗
04 / Left source list · key inspector

Split View

Keep the key list on the left and settings on the right. Compact toolbar navigation opens profiles and token-filtered activity.

Explore prototype ↗
05 / Ambient workflow · popover + window

Menu Bar

Keep Clavis close to your work. A compact status popover provides quick approval and opens the full management window when you need it.

HTML, CSS and JavaScript approximations of macOS materials. Mock data only; no real key generation, process verification, signing or authentication. Changes reset on reload.
Every direction includes Keys, Application Profiles, per-key authentication settings, token-filtered Activity and first-use approval. Cmd/Ctrl+K focuses key search; Cmd/Ctrl+N creates a mock key.
