Clavis / macOS 27 navigation studies

A quieter way
to find your keys.

Five alternatives to the earlier navigation sidebar, based on your preferred token-history window. The first two use a single key source list; the other three have no permanent sidebar.

01 / Single source list · reference direction

Reference Source List

Closest to your preferred window. One source list with keys, compact window controls and a quiet history toolbar.

Explore navigation ↗
02 / Compact source list · toolbar navigation

Compact Source List

A narrower key list with denser rows. Key settings, Activity and Profiles move into one toolbar control.

Explore navigation ↗
03 / No sidebar · title menu

Title-bar Picker

No permanent sidebar. Switch keys from the title, with the whole window available for settings or history.

Explore navigation ↗
04 / No sidebar · horizontal selection

Horizontal Key Strip

Key selection runs horizontally below the toolbar. History keeps its token filters without a left column.

Explore navigation ↗
05 / No sidebar · browse and drill in

Key Browser

Start in a compact key table. Open a key in place, then use Back to return to the list.

Explore navigation ↗

All five keep application icons, per-key authentication settings, profiles and token-filtered history. No owner hierarchy or Requests view.
